# My_Python_Project-2
## Project Objective
The objective of this project is to analyze income, debt risk, age, and credit score data to identify important financial patterns and relationships. The analysis focuses on comparing annual and monthly income across different categories, studying credit scores based on age groups, and understanding the relationship between income and debt risk. Data visualization is used to present the findings clearly and derive meaningful insights that can support better financial analysis and decision-making.
- <a href="https://github.com/meeran147-sketch/My_Python_Project-1/blob/main/Coffee_Shop_Sales_Dataset.xlsx">Dataset</a>

## Question
- What is the total annual income across different income groups?
- Which income group has the highest annual income?
- How does monthly income vary across different debt-risk categories?
- Which debt-risk category has the highest monthly income?
- How does credit score vary across different age groups?
- Which age group has the highest average credit score?
- Is there any relationship between annual income and income group?
- How are income levels associated with different debt-risk categories?
- Which customer group shows the highest credit score and income?
- What financial insights can be derived from the relationship between income, age, debt risk, and credit score?
  
  - Code  access <a "https://github.com/meeran147-sketch/Python_Project_2-/blob/main/Python_Code">View Dashboard</a>

## Process

- Data Collection : Gathered customer financial data including annual income, monthly income, age, credit score, and debt risk category.
- Data Cleaning : Removed missing values, corrected data inconsistencies, and organized the dataset for accurate analysis.
- Data Transformation: Created categories such as income groups, age groups, and debt risk levels to simplify the analysis.
- Data Analysis: Analyzed relationships between income, debt risk, age, and credit score using statistical methods and aggregations.
- Data Visualization: Developed charts such as line plots, bar charts, and scatter plots to represent trends and comparisons clearly.
- Insight Generation: Derived meaningful insights from the visualizations to understand customer financial behavior and credit patterns.
